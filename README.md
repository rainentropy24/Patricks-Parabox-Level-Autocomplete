A python script that automatically completes levels in Patrick's Parabox
I'm an amateur, didn't know how to do it myself, so I used Claude. It worked eventually, so I'm uploading for whoever else wants to use it.

Usage Steps:

    1. Open the guide authored by nana on Steam Community:
       https://steamcommunity.com/sharedfiles/filedetails/?id=2786724419

    2. Copy the input sequence for the level you want to complete

    3. Paste the sequence in the sequence.txt

    4. Run the batch file and focus the game window

    The script has a 3 second delay before executing the input sequence. Make sure you start from a fresh restarted level
    The mapping JSON can be used to change what letters pertain to each key on your keyboard
